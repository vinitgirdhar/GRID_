### 2. TYPOGRAPHY (EXACT from design.md)

**Headings (Outfit)**
- Usage: Page titles, primary numbers, massive metrics
- Weights: ONLY font-light (300) or font-medium (500)
- Never use ultra-heavy weights
- Tailwind class: `font-heading`

**Body (Inter)**
- Usage: Paragraphs, descriptions, general UI text
- Weights: font-normal (400) or font-light (300)
- Tailwind class: `font-body`

**Data & Labels (JetBrains Mono)**
- Usage: Eyebrow text, table headers, small tracking numbers, tags
- ALWAYS pair with `uppercase` and `tracking-widest`
- Tailwind class: `font-mono`

## Core Philosophy (from design.md)

"GRID is built for fleet operators and drivers. The UI needs to be high-contrast, distraction-free, and easy to read at a glance. We favor deep dark backgrounds with sharp, glowing accents. Keep cognitive load low. If a driver can't read a card in one second, it needs less text and more visual hierarchy."

**This means**:
- Visual hierarchy that jumps out in 1 second
- Deep navy (#050514) is the only main background
- Sharp yellow (#facc15) accents only
- Glassy effects (bg-white/5) over solid colors
- Micro-interactions serve the aesthetic (hover:-translate-y-1, smooth transitions)
- Every element has purpose—no visual fluff
